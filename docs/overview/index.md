# Overview

High-level information about AICP.

## What is AICP?

AICP (AI Capability Protocol) is a standard for:
- **Capability-aware** execution - Rich capability definitions
- **Workflow-aware** execution - Multi-step processes with state
- **Policy-aware** execution - Explicit access control
