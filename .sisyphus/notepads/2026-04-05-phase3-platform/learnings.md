- Phase 3 platform adapter work in `apps/mammoth` required adding `crates/adapters/*` explicitly to the workspace while avoiding the invalid intermediate `crates/adapters/` wildcard match.
- The runtime crate package name is now `mammoth-runtime`; existing workspace crates can keep `runtime::...` source imports by using dependency key `runtime = { package = "mammoth-runtime", path = "../runtime" }`, while new adapter crates can import `mammoth_runtime::...` via dependency key `mammoth-runtime = { path = "../../runtime" }`.
- The plan's original generic `ChannelAdapter::run<F>(...)` signature is incompatible with `Arc<dyn ChannelAdapter>` storage in the registry; using `Arc<dyn Fn(NormalizedMessage) -> anyhow::Result<()> + Send + Sync>` makes the adapter trait object-safe while preserving callback semantics.
- Targeted verification that passed during implementation: `cargo test -p mammoth-runtime adapter -- --nocapture`, `cargo test -p mammoth-adapter-telegram -- --nocapture`, `cargo test -p mammoth-adapter-discord -- --nocapture`, `cargo test -p mammoth-adapter-slack -- --nocapture`, `cargo test -p mammoth-runtime adapter_registry -- --nocapture`, and `cargo build -p mammoth-cli`.
